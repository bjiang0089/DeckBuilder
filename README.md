Welcome to the DeckBuilder wiki!

I wanted to create a custom deck building tool and card catalog where I can create decks using my own homebrewed cards. 
This project is being modeled after [Moxfield](https://moxfield.com), an online deck building website for Magic the Gathering.

Core functionality:
- Create, edit, and delete custom magic cards.
- Create, edit, and delete magic decks.
- Seach the Scryfall Database to find and add existing Magic card.
- Additionally search the local database for custom cards.
